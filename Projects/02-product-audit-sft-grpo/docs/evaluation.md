# 评测口径

冻结测试集按商品组切分并绑定策略版本。阈值只允许在校准集选择，测试集不得反复调参。

| 指标 | 定义 | 用途 |
|---|---|---|
| Schema Valid Rate | 通过严格协议校验的输出占比 | 衡量服务可消费性 |
| Risk Macro-F1 | 各风险代码 F1 的宏平均 | 避免高频安全样本掩盖长尾风险 |
| High-risk FNR | 高风险样本被判为非拒绝的比例 | 衡量漏审 |
| Auto-reject FPR | 合规样本被自动拒绝的比例 | 衡量误杀 |
| Evidence P/R | 风险证据与人工证据的匹配率 | 衡量可核验性 |
| Policy Violation Rate | 模型结论违反硬规则的比例 | 衡量规则遵循 |
| Manual Review Rate | 进入人工复核的样本占比 | 衡量自动化覆盖 |
| ECE | 外部置信度校准误差 | 选择自动执行阈值 |

证据框 IoU 只是区域级匹配的一部分。整图证据按媒体序号匹配，文本证据还要核对对应风险代码与策略条款。

每次报告必须给出总体结果、95% bootstrap 置信区间、分片结果和错误样例。建议消融顺序：仅规则、仅 SFT、SFT+GRPO、移除硬规则门控、移除证据奖励、移除策略引用奖励。
